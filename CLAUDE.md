# Pilot Academy

**Read [`agent.md`](agent.md) before starting any task.** It is the single guide
for this repo: project overview, how to work, standing instructions, invariants,
the work log, how to verify, and the traps already paid for.

Rules live in `agent.md` only. Do not add them here.

The short version, which `agent.md` explains:

- Agents do not commit or push. Leave changes uncommitted. Branch off `laravel`,
  open PRs into `laravel`, and do not self-merge.
- Keep changes small, reuse existing code, and touch only the files the task needs.
- Student pages must work at ~375px.
- Visible changes update `docs/CHANGELOG.md` and the guides in the same change,
  plus a work-log entry in `agent.md`.
- Never claim something is verified unless you ran it.
