# أكاديمية بايلوت — دليل الإدارة

دليل لإنشاء الدورات، إدارة الاختبار النهائي، وإصدار الشهادات.

## 1. تسجيل الدخول والتوجيه

افتح عنوان الموقع وأضف `/admin`. قم بتسجيل الدخول ببريدك الإلكتروني وكلمة المرور الخاصة بالمسؤول.

ستدخل إلى **لوحة المعلومات**، حيث ترى الطلاب، التقدم، الدورات المنشورة والشهادات المصدرة. القائمة اليسرى تنقلك إلى كل جزء من الأكاديمية.

قم بتغيير اسمك أو بريدك الإلكتروني أو كلمة المرور من قائمة الحساب في الزاوية العلوية اليمنى ضمن **الملف الشخصي**.

يرى المسؤولون نشاط الطلاب، التقدم والشهادات. **الطلاب النشطون** تحسب أولئك الذين قاموا بتسجيل الدخول أو عملوا في الأكاديمية خلال آخر 30 يومًا.

## 2. نظرة سريعة على القائمة

| عنصر القائمة | الغرض منه |
|---|---|
| **لوحة المعلومات** | الأرقام العامة، التقدم حسب الشركة، والطلاب غير النشطين. |
| **المحتوى ← الدورات** | إنشاء الدورات، تفعيل الاختبار النهائي والشهادة. |
| **المحتوى ← الدروس** | إضافة فيديو، نص، وأسئلة. |
| **المحتوى ← دراسات الحالة** | إنشاء ومعاينة ونشر أدلة التنفيذ العملي للشركاء. |
| **المحتوى ← الندوات** | جدولة الجلسات المباشرة، ومشاركة رابط الانضمام، وإضافة التسجيل لاحقًا. |
| **المحتوى ← الشروحات** | مقاطع فيديو تعليمية مستقلة. |
| **المحتوى ← المنتجات** | المنتجات أو وحدات التدريب والمسؤولون عنها. |
| **المحتوى ← عناصر الوسائط** | مكتبة صور مشتركة. |
| **المحتوى ← سلامة المحتوى** | المشكلات التي يجب إصلاحها. |
| **الأشخاص ← المستخدمون** | الحسابات، الأدوار، التقدم والشهادات. |
| **الأشخاص ← الشركات** | الشركات الشريكة وطلابها. |
| **النتائج ← الشهادات** | تنزيل، إعادة إرسال، أو إلغاء الشهادات. |
| **النتائج ← أداء الاختبار النهائي** | جودة الاختبار النهائي. |
| **النتائج ← محاولات الاختبار** | محاولات الطلاب في الاختبارات. |
| **النتائج ← آراء الطلاب** | تعليقات الطلاب. |
| **الوثائق ← الدليل** | هذا الدليل. |
| **الوثائق ← ما الجديد** | أحدث التغييرات وملاحظات الإصدار. |
| **الإعدادات ← البريد** | إعدادات البريد. |
| **الإعدادات ← الترجمات** | ترجمات النظام. |
| **الإعدادات ← التكاملات** | رموز DeepL وChatGPT وDeepSeek لمسودات الترجمة. للمسؤولين فقط. |

الطلاب لديهم دليل خاص بهم في **المساعدة**، الزر **?** في الشريط العلوي.

## 3. بدء سريع: من دورة فارغة إلى شهادة

المسار دائماً هو: **إنشاء دورة → إضافة دروس → تفعيل الاختبار النهائي → النشر → ينجح الطالب → يحصل على شهادة**.

### الخطوة 1 · إنشاء دورة
في **Courses**، انقر على **New course**. املأ العنوان والوصف.

### الخطوة 2 · إضافة دروس
في **Lessons**، قم بإنشاء درس، اختر الدورة، أضف فيديو ونص وأسئلة.

### الخطوة 3 · تفعيل الاختبار النهائي
في الدورة، قم بتفعيل **Final quiz & certificate**، حدد درجة النجاح وعدد الأسئلة.

### الخطوة 4 · نشر الدورة
في قائمة الدورات، استخدم **Publish**.

### الخطوة 5 · التجربة كطالب
افتح الموقع العام واختبر الدرس والاختبار.

### الخطوة 6 · الشهادة
عند النجاح، يتم إنشاء الشهادة تلقائياً.

## 4. كيفية تكوين الأشياء

يمكنك تكرار الدورات من قائمة الدورات عندما تريد إعادة استخدام بنية.
لإضافة شركة وطالب: قم بإنشاء الشركة في **Companies** ثم أنشئ المستخدم.

## 5. كيفية مراجعة النتائج

استخدم **Users** لتصفية الأدوار وفتح تقدم الطالب.
لوحة المعلومات تعرض الإحصائيات الشاملة.
في **Certificates**، قم بتصفية الشهادات وتنزيلها.

## 6. ماذا تفعل إذا...

| الموقف | ماذا تفعل |
|---|---|
| لم يستلم الطالب البريد الإلكتروني | أعد إرساله من **Certificates**. |
| تم إصدارها بالخطأ | استخدم **Revoke**. |
| ملف PDF فارغ | استخدم **Regenerate PDF**. |
| تحتاج إلى تقرير | قم بتصدير CSV من **Certificates**. |

## 7. الأسئلة الشائعة

**هل تنتهي صلاحية الشهادات؟** لا.
**هل يمكن إعادة الاختبار بعد النجاح؟** لا.
**من أين يأتي اسم الشهادة؟** من الاسم الذي كتبه الطالب.

## 8. المصطلحات المستخدمة

| المصطلح | المعنى |
|---|---|
| الاختبار النهائي | اختبار الدورة كاملة. |
| الشهادة | ملف PDF يثبت اجتياز الدورة. |
| مسودة | غير مرئي للطلاب. |
| منشور | مرئي في موقع الطالب. |

## ترجمة الفيديو باستخدام Descript

ترجمة Descript منفصلة عن زر **الترجمة** العادي، الذي يظل الطريقة المستخدمة
لترجمة عناوين الدورات والدروس وملخصاتها ونصوصها يدويًا.

يفتح المسؤول أولًا **الأشخاص ← المستخدمون**، ثم حساب الموظف، ويحدد **استخدام
ترجمة فيديو Descript** ضمن **الصلاحيات الإضافية** ويحفظ. ويجب أيضًا تفعيل تكامل
Descript الاختياري على الخادم. لا تُمنح هذه الصلاحية تلقائيًا لدور المسؤول أو
المنشئ.

في درس يحتوي على فيديو مرفوع، ينقر الشخص المصرح له **ترجمة الفيديو**، ويختار
الملف واللغات، ثم يؤكد أن الفيديو سيُرسل إلى Descript وقد يستهلك دقائق الوسائط
وأرصدة الذكاء الاصطناعي. لا يُرسل شيء قبل النقر على **بدء الترجمة**. لا يمكن
إرسال روابط YouTube. استخدم **فحص التقدم** حتى يتم حفظ النتيجة.
