# Aide

Comment fonctionne Pilot Academy, de votre première leçon à votre certificat.

## Premiers pas

**Vous pouvez commencer une leçon sans compte.** Ouvrez un cours depuis l'accueil et avancez. Votre progression reste alors uniquement dans ce navigateur.

**Connectez-vous pour conserver votre progression partout** et passer le quiz final. Utilisez **Connexion** ou **S’inscrire**. Si votre entreprise vous a envoyé un lien personnel, ouvrez-le : il vous connecte directement.

**L’académie s’affiche dans la langue de votre navigateur :** anglais, russe, espagnol, français ou portugais. Pour en choisir une autre, utilisez le menu des langues dans la barre du haut sur ordinateur ou tablette. Le texte des cours et des leçons s’affiche tel qu’il a été rédigé.

## Fonctionnement d'un cours

Un cours est une série de **leçons à suivre dans l'ordre**. La page du cours affiche votre progression, par exemple **3 / 8 leçons · 32 min restantes**.

Certaines leçons font partie de plusieurs cours. Vous ne les suivez qu’une fois : une leçon terminée compte comme terminée dans tous les cours où elle apparaît.

La carte en haut de l'accueil indique toujours la prochaine étape : commencer, reprendre où vous vous êtes arrêté ou ouvrir le quiz final lorsqu'il est prêt.

La recherche trouve les cours et les leçons par nom, ainsi que les mots prononcés dans une vidéo lorsqu'une transcription existe.

## Terminer une leçon

Une leçon est terminée lorsque vous **réussissez son contrôle de connaissances**. Lire ou regarder ne suffit pas.

- Regardez la vidéo. Si vous êtes connecté, elle reprend où vous vous étiez arrêté.
- Vous préférez lire ? Ouvrez **Transcription**.
- Répondez correctement à toutes les questions. En cas d'erreur, relisez la leçon et réessayez.

Certains contrôles ont une limite de temps ou un nombre limité d'essais. Ces règles sont affichées avant de commencer.

## Le quiz final

Lorsque toutes les leçons d'un cours sont terminées, le **quiz final** se débloque. Vous devez être connecté.

- Vous voyez le score minimum, le nombre de questions et les essais restants.
- Saisissez votre nom complet exactement comme il doit apparaître sur le certificat.
- Chaque essai peut tirer une nouvelle série de questions.
- Une fois réussi, le quiz est fermé et le certificat est émis.

## Votre certificat

Après réussite, votre certificat est créé immédiatement : un PDF avec votre nom, le cours, la date, un numéro unique et un QR code.

- Il vous est envoyé par e-mail.
- Il reste disponible dans **Certificats** dans la barre supérieure.
- Toute personne peut le vérifier avec le QR code ou le lien de vérification.

Les certificats n'expirent pas.

## Donner votre avis

Lorsque vous terminez un cours, la carte **Cours terminé** vous demande s'il a été utile. Vous pouvez répondre par pouce levé ou baissé et ajouter un commentaire. Seule l'équipe de l'académie le lit.

## Si quelque chose ne fonctionne pas

**Ma progression a disparu.** Vous n'étiez probablement pas connecté, ou vous utilisez un autre navigateur. Connectez-vous pour la conserver.

**La leçon ne se termine pas.** Toutes les réponses du contrôle doivent être correctes.

**Le quiz final est encore verrouillé.** Une leçon n'est pas encore terminée. Sur la page du cours, cherchez celle sans coche.

**Je n'ai plus d'essais.** Contactez l'administrateur de votre académie.

**Le nom sur mon certificat est incorrect.** Contactez l'administrateur.

**Je n'ai pas reçu l'e-mail du certificat.** Téléchargez-le depuis **Certificats**.
