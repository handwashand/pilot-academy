# Pilot Academy — Руководство администратора

Руководство по созданию курсов, настройке итогового теста и выдаче сертификатов.

## 1. Вход и навигация

Откройте адрес сайта и добавьте `/admin`. Войдите с почтой и паролем администратора.

Вы попадёте на **Панель**: здесь видно студентов, прогресс, опубликованные курсы и выданные сертификаты. Левое меню ведёт во все разделы академии.

Имя, почту или пароль можно изменить в меню аккаунта справа сверху, в разделе **Profile**.

## 2. Меню в двух словах

| Пункт | Для чего нужен |
|---|---|
| **Инфопанель** | Общие показатели, прогресс по компаниям и неактивные студенты. |
| **Контент → Курсы** | Создание курсов, итоговый тест и сертификат. |
| **Контент → Уроки** | Видео, текст и вопросы уроков. |
| **Контент → Продукты** | Продукты или модули обучения и ответственные за них. |
| **Контент → Медиафайлы** | Общая библиотека изображений. |
| **Люди → Пользователи** | Аккаунты, роли, прогресс и сертификаты. |
| **Люди → Компании** | Компании-партнёры и их студенты. |
| **Результаты → Сертификаты** | Скачать, отправить повторно, отозвать или восстановить сертификат. |
| **Результаты → Качество итогового теста** | Понять, слишком лёгкий или сложный итоговый тест. |
| **Документация → Руководство** | Это руководство. |
| **Документация → Что нового** | Изменения и заметки о версиях. |

У студентов есть своё руководство в **Помощи**, кнопка **?** в верхней панели.

## 3. Быстрый старт: от пустого курса до сертификата

Порядок всегда один: **создать курс → добавить уроки → включить итоговый тест → опубликовать → студент сдаёт → получает сертификат**.

### Шаг 1 · Создать курс

В **Courses** нажмите **New course**. Заполните название, краткое описание, длительность, уровень и продукт/модуль. Новый курс сохраняется как **Draft**.

### Шаг 2 · Добавить уроки

В **Lessons** создайте урок, выберите курс, добавьте видео, текст, длительность, расшифровку и вопросы. Уроку нужна проверка знаний, иначе студент не сможет завершить его.

Порядок уроков меняется во вкладке **Lessons** внутри курса. Перемещение существующего урока забирает его из прежнего курса; чтобы скопировать материал, используйте **Duplicate** у курса.

### Шаг 3 · Включить итоговый тест

В курсе включите **Final quiz & certificate**, задайте проходной балл, количество вопросов за попытку и максимум попыток. Затем добавьте вопросы во вкладке **Final questions**.

### Шаг 4 · Опубликовать курс

В списке курсов используйте **Publish**. В курсе должен быть хотя бы один опубликованный урок. **Unpublish** скрывает курс, но не удаляет содержимое, прогресс и сертификаты.

### Шаг 5 · Проверить как студент

Откройте публичный сайт, завершите уроки и убедитесь, что итоговый тест открывается.

### Шаг 6 · Сертификат

После успешной сдачи сертификат создаётся автоматически: PDF с именем, курсом, датой, уникальным номером и QR-кодом.

## 4. Настройка

Вопросы итогового теста редактируются во вкладке **Final questions** курса. Вопрос из урока остаётся тем же вопросом; изменение затронет и урок.

Фон сертификата загружается в **Final quiz & certificate → Certificate background**. Используйте изображение A4 в альбомной ориентации или оставьте пустым для встроенного шаблона.

Дублируйте курс из строки курса, если хотите повторить структуру. Копия — независимый черновик; прогресс и сертификаты не копируются.

Чтобы владелец продукта создавал обучение сам, дайте ему роль **Creator** и отметьте его продукты в **Users**. Он увидит только курсы и уроки этих продуктов.

Чтобы добавить компанию и студента, создайте компанию в **Companies**, затем пользователя с этой компанией и ролью.

## 5. Проверка результатов

В **Users** фильтруйте по ролям и открывайте прогресс конкретного студента.

**Панель** показывает проблемы в контенте, показатели, прогресс по компаниям, неактивных студентов, сложные уроки, активность и самые открываемые курсы.

В **Student feedback** внутри курса читайте приватные отзывы студентов.

В **Students who have gone quiet** используйте **Send reminder**. Один студент не получит два напоминания в течение 7 дней.

Используйте **Ctrl+K** или **⌘K**, чтобы быстро искать курсы, уроки и людей.

В **Final quiz health** смотрите процент сдачи с первой попытки и дни до сертификата.

В **What's new** смотрите изменения по версиям или скачивайте PDF.

В **Certificates** фильтруйте по курсу, компании или статусу. Публичная страница `/certificates/{number}` проверяет сертификат.

## 6. Что делать, если…

| Ситуация | Действие |
|---|---|
| Студент не получил письмо | Отправьте повторно из **Certificates**. |
| Сертификат выдан по ошибке | Используйте **Revoke**. |
| PDF пустой или не скачивается | Используйте **Regenerate PDF**, затем скачайте снова. |
| Нужен отчёт | Экспортируйте CSV из **Certificates** или **Users**. |
| Закончились попытки | Увеличьте или очистите максимум попыток в курсе. |
| Студенты не видят курс | Проверьте, что он **Published**. |
| Пропал урок | Проверьте, что курс и урок опубликованы. |
| Creator не видит курс | Проверьте **Product / module** курса. |
| Нужно скрыть курс или урок | Используйте **Unpublish**. |

## 7. Частые вопросы

**Сертификаты истекают?** Нет.

**Можно пересдать итоговый тест после успешной сдачи?** Нет.

**Откуда берётся имя в сертификате?** Из имени, которое студент вводит перед итоговым тестом.

**Что если почта не настроена?** Сертификат всё равно создаётся и доступен для скачивания.

**Можно изменить проходной балл?** Да, отдельно для каждого курса.

**Сколько сертификатов может быть у студента по одному курсу?** Один действительный.

**Можно проверить итоговый тест без завершения уроков?** Да, администраторы могут пройти его для проверки и затем отозвать тестовый сертификат.

## 8. Термины

| Термин | Значение |
|---|---|
| Итоговый тест | Проверка по всему курсу. |
| Банк вопросов | Набор вопросов итогового теста. |
| Проходной балл | Процент, нужный для сдачи. |
| Попытка | Один проход теста. |
| Сертификат | PDF-доказательство успешного прохождения. |
| Отозвать | Сделать сертификат недействительным. |
| Партнёр | Компания, к которой относятся студенты. |
| Admin | Управляет всей платформой. |
| Creator | Создаёт обучение для своих продуктов. |
| Learner | Проходит курсы. |
| Draft | Не виден студентам. |
| Published | Видим на студенческом сайте. |
| Archived | Скрыт, но сохранён. |
